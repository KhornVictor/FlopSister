# OWASP Top 10 (2021) Security Checklist & Verification

This document audits the security posture of the **shop-secure** application against the **OWASP Top 10:2021** standard, mapping controls, implementation locations, and automated test / transcript evidence.

| Category | Status | Control Implementation | Evidence (Tests & Transcripts) |
|---|---|---|---|
| **A01:2021 – Broken Access Control** | **Enforced** | Method security via `@EnableMethodSecurity` (`MethodSecurityConfig`), `@PreAuthorize` and `@PostAuthorize` owner checks in `OrderService`, URL-level authorization with strict deny-by-default (`SecurityConfig.java`), `RoleHierarchy` (`ADMIN > CUSTOMER`). | `OrderServiceSecurityTest` (5 tests), `OrderControllerSecurityTest` (3 tests), `security-session.md` (Task 1, 3, 5 transcripts). |
| **A02:2021 – Cryptographic Failures** | **Enforced** | BCrypt password hashing via `PasswordEncoderFactories.createDelegatingPasswordEncoder()` (`PasswordConfig`), HS256 HMAC JWT signing with 256-bit+ secret (`JwtConfig`), SHA-256 refresh token hashing (`RefreshTokenService`), HSTS (`Strict-Transport-Security: max-age=31536000; includeSubDomains`). | `AccountIntegrationTest` (BCrypt hash verification), `AuthFlowIT`, `HardeningSecurityTest#securityHeadersArePresent`, `security-session.md`. |
| **A03:2021 – Injection** | **Enforced** | Parameterized queries and Spring Data JPA repositories preventing SQL injection; stored XSS defeated via Thymeleaf contextual HTML escaping (`th:text`) and Jackson JSON escaping with `nosniff`. | `HardeningSecurityTest#storedXssPayloadIsStoredAndEscapedInHtml`, `ProductSecurityTest`, `security-session.md` (XSS demo and screenshots `docs/screenshots/xss-safe.png`). |
| **A04:2021 – Insecure Design** | **Enforced** | Refresh token rotation with family revocation upon reuse detection (`RefreshTokenService`), account lockout after 5 consecutive failures (`LockoutListener`), rate limiting on `/api/auth/login` (`RateLimiterService`), generic 401 error details preventing username and account state enumeration. | `AuthLifecycleIT` (token rotation, reuse detection, lockout, rate limiting tests), `security-session.md`. |
| **A05:2021 – Security Misconfiguration** | **Enforced** | Hardened HTTP response headers (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy`, `Referrer-Policy`), single-origin CORS configuration (`CorsConfig`), disabled `formLogin`, CSRF disabled with documented justification (`docs/csrf.md`), fail-fast property validation (`SecurityProps`). | `HardeningSecurityTest`, `security-session.md` (header verification block, CORS preflight and disallowed origin rejection, `docs/screenshots/jwt-secret-missing.png`). |
| **A06:2021 – Vulnerable and Outdated Components** | **Gap / Planned** | **Identified Gap:** The project uses curated Spring Boot 4.1.2 parent dependencies, but lacks automated continuous dependency vulnerability scanning in CI.<br>**Planned Mitigation:** Integrate the OWASP Dependency-Check Maven plugin (`dependency-check-maven`) and GitHub Dependabot / Snyk into CI/CD pipeline to block builds on known CVEs. | Planned mitigation in CI workflow. |
| **A07:2021 – Identification and Authentication Failures** | **Enforced** | Strong password policy in `RegisterRequest` (12–72 chars, upper, lower, digit), rate limiting (5 attempts/min per IP and username via `RateLimiterService`), automatic account lockout (15 minutes after 5 failures in `LockoutListener`), stateless JWT authentication (`AuthController`, `JwtConfig`). | `AccountIntegrationTest#invalidRegistrationReturnsBadRequest`, `AuthFlowIT`, `AuthLifecycleIT#lockoutAfterFiveFailures`, `AuthLifecycleIT#rateLimiterReturns429`. |
| **A08:2021 – Software and Data Integrity Failures** | **Enforced** | Nimbus JWT signature and issuer validation (`JwtValidators.createDefaultWithIssuer("shop-api")`), cryptographically strong 32-byte random refresh tokens stored as SHA-256 hashes, automatic invalidation of entire token family upon reuse. | `AuthFlowIT#loginIssuesUsableJwtWithExpectedClaims`, `AuthLifecycleIT#reuseOfOldRefreshTokenRevokesFamily`. |
| **A09:2021 – Security Logging and Monitoring Failures** | **Enforced** | Dedicated `SECURITY` logger (`SecurityEventLogger`) tracking authentication successes, failures, and access denials with raw tokens redacted; unique request correlation IDs (`rid`) via `RequestIdFilter`; `AuditService` persisting 8 critical security events to `security_audit` table with `REQUIRES_NEW` transactions; `AdminAuditController` restricted to `ADMIN`. | `security-session.md` (correlated log lines with `rid`), `AuthLifecycleIT#auditLogsPersistedAndAccessibleToAdmin`. |
| **A10:2021 – Server-Side Request Forgery (SSRF)** | **Gap / Planned** | **Identified Gap:** No outgoing HTTP client or user-supplied URL fetching exists in the current product catalog application.<br>**Planned Mitigation:** If webhook or remote media retrieval features are added, implement strict domain allowlists, block private/loopback IP ranges (RFC 1918, RFC 3927), disable HTTP redirects, and enforce DNS pinning. | Planned mitigation for future outbound integrations. |
